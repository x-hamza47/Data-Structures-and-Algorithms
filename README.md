## 📌 Overview

This repo is where I write and test C++ code while learning core Data Structures & Algorithms concepts. Small, focused programs, built to understand how things actually work rather than to be reused as a library.

<br>

## 🧠 Topics

### 🔢 Arrays
- 🔍 Linear search
- 📉 Finding the smallest and largest element
- ➕ Sum and product of array elements
- 🔄 Reversing an array (swap-based)
- 🤝 Finding common elements between two arrays
- 🎯 Finding elements that appear only once

### 🔁 Loops & Pattern Printing
- ⬛ Squares, triangles, inverted triangles, pyramids
- 💎 Hollow diamond and character-based shapes
